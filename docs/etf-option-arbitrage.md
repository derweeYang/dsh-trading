# ETF 期权套利与价差组合

> 知识层：期权策略（L3 策略/实战）
> 适用范围：中国交易所上市 ETF 期权（50ETF/300ETF/500ETF/创业板ETF/科创50ETF/深证100ETF 等）
> 性质：定价与组合构造的**知识性说明**，非投资建议。

## 0. 结论先行

三者里**只有平价套利与箱型套利是真正的无风险套利**——到期损益被锁定，与标的价格无关；**垂直套利本质是一个方向性价差**（有方向暴露，不是套利，只是"用卖出腿降低权利金成本"）。

| 名称 | 类型 | 到期损益是否锁定 | 腿数 | 方向暴露 |
|---|---|---|---|---|
| 平价套利矩阵 | 真套利（市场中性） | 是 | 4 腿（C / P / 标的 / 现金） | 无 |
| 垂直套利组合 | 方向性价差 | 否 | 2 腿（同到期不同 K） | 有 |
| 箱型套利组合 | 真套利（锁定利率） | 是 | 4 腿（2 个垂直价差） | 无 |

## 1. 平价套利矩阵（Put-Call Parity Arbitrage）

### 1.1 推导

对**欧式**期权，同一标的、同行权价 K、同到期 T 的看涨与看跌满足：

```
C + K·e^(-rT) = P + S₀
```

- 左边 = 持 Call + 按无风险利率借入 K·e^(-rT)
- 右边 = 持 Put + 持现货

两者到期都正好等于 `max(S_T − K, 0)`，故现值必相等。移项得：

```
C − P = S₀ − K·e^(-rT)
```

- 左边 `C − P` 是**合成远期多头**
- 右边 `S₀ − K·e^(-rT)` 是**现货远期多头**

### 1.2 构建（"矩阵"含义）

所谓"矩阵"，即对**每个到期日 × 每个行权价**批量计算偏离额：

```
偏离 = (C − P) − (S₀ − K·e^(-rT))
```

偏离 ≠ 0 即存在套利空间，挑偏离最大的行权价对下手：

| 情景 | 判断 | 四腿组合 | 锁定利润 |
|---|---|---|---|
| A | `C−P` 偏高（购权贵） | 卖 Call、买 Put、买现货、借入 K·e^(-rT) | `(C−P) − (S₀−K·e^(-rT)) > 0` |
| B | `C−P` 偏低（沽权贵） | 买 Call、卖 Put、卖空现货、贷出 K·e^(-rT) | `(S₀−K·e^(-rT)) − (C−P) > 0` |

### 1.3 关键前提

- 严格等式只在**欧式**期权成立；中国 ETF 期权均为欧式、现金交割，可直接套用。
- 若为美式，则退化为不等式 `C − P ≥ S₀ − K`，套利方向只剩"购权贵"一侧（美式 Put 有提前行权价值，下界更高）。
- 必须按**可成交价**（买价/卖价）而非中间价核算，且覆盖手续费、滑点、融券/借券成本。

## 2. 垂直套利组合（Vertical Spread）

### 2.1 定义

**同到期、不同行权价**的一买一卖，用卖出腿抵减买入腿权利金，换取有限的盈利与亏损。按"看涨/看跌 × 牛/熊"分四种：

| 组合 | 买 | 卖 | 观点 | 最大盈利 | 最大亏损 |
|---|---|---|---|---|---|
| 牛市看涨价差 | 低 K Call | 高 K Call | 温和看涨 | `K₂−K₁−净支出` | 净支出 |
| 熊市看涨价差 | 高 K Call | 低 K Call | 温和看跌 | 净收入 | `K₂−K₁−净收入` |
| 牛市看跌价差 | 低 K Put | 高 K Put | 温和看涨 | 净收入 | `K₂−K₁−净收入` |
| 熊市看跌价差 | 高 K Put | 低 K Put | 温和看跌 | `K₂−K₁−净支出` | 净支出 |

### 2.2 构建示例（牛市看涨价差）

买 `K₁=40` Call、卖 `K₂=60` Call，净支出 8（对应损益图）：

```
损益 = max(S_T − 40, 0) − max(S_T − 60, 0) − 8
```

- `S_T ≤ 40`：亏 8（最大亏损，封顶）
- `40 < S_T < 60`：盈利随标的线性上升
- `S_T ≥ 60`：赚 12（最大盈利，封顶）
- 盈亏平衡：`S_T = 48`

### 2.3 与套利的区别

损益仍由 `S_T` 决定，方向看反即亏到最大，只是把亏损/盈利都封顶。它解决的是"看对方向但嫌权利金贵"的性价比问题，而非无风险套利。

## 3. 箱型套利组合（Box Spread）

### 3.1 推导

箱型 = 同一对 `K₁ < K₂` 上的**牛市看涨价差 + 熊市看跌价差**拼起来：

```
买 C₁, 卖 C₂      (牛市看涨)
买 P₂, 卖 P₁      (熊市看跌)
```

把四个腿的到期 payoff 相加，K₁ 与 K₂ 之间的任何 S_T 都抵消，结果恒为 **`K₂ − K₁`**，与标的价格完全无关。

- 公平成本 ≈ `(K₂ − K₁)·e^(-rT)`
- 若市场报价偏离，做多/做空箱型即可锁定无风险利差（损益图两条细线之差）

### 3.2 构建

| 情景 | 判断 | 四腿组合 | 结果 |
|---|---|---|---|
| 箱型偏便宜 | 报价 < 贴现值 | 买 C₁、卖 C₂、买 P₂、卖 P₁（做多箱型） | 到期收 `K₂−K₁`，利差为正 |
| 箱型偏贵 | 报价 > 贴现值 | 反向（做空箱型） | 借入 `K₂−K₁`，利差为正 |

### 3.3 本质

箱型是无风险借贷的衍生品：
- 多头箱型 ≈ 以锁定利率**贷出** `K₂ − K₁`
- 空头箱型 ≈ 以锁定利率**借入** `K₂ − K₁`

实务上它更像"期权市场给你的一个固定收益报价"，而非靠判断标的赚钱。

## 4. 中国 ETF 期权实操要点

1. **欧式 + 现金交割**：50ETF(510050)/300ETF(510300、159919)/500ETF(510500)/创业板ETF(159915)/科创50ETF(588000)/深证100ETF(159901) 等均为欧式，平价与箱型可严格套用。
2. **合约乘数 10000**：上述损益需 ×10000 才是实际金额；平价偏离需覆盖手续费 + 滑点 + 行权/交割成本才值得做。
3. **保证金**：套利腿中"卖 Call / 卖 Put / 卖空现货"占保证金；平价套利常需融券（ETF 融券可得性影响落地）；箱型两头一买一卖，保证金通常可对冲减免。
4. **流动性与冲击成本**：深度实/虚值腿价差大，矩阵扫出的"偏离"很多是报价噪声，需按可成交价复核。

## 5. 延伸：实盘落地路径

对特定标的（如 50ETF/300ETF）拉取实时期权链后，可程序化执行：

1. 按到期日分组，取每个 K 的 `(C_bid − P_ask)` 与 `(C_ask − P_bid)` 构成无套利区间；
2. 对每个 K 计算 `偏离 = (C − P) − (S₀ − K·e^(-rT))`，用可成交买卖价取保守值；
3. 筛选 `|偏离| × 10000 > 交易成本` 的行权价对，输出套利方向与四腿订单；
4. 箱型同理：扫描同到期同 K₁/K₂ 的箱型报价与贴现值之差。
